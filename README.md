# 🎮 Guess The Number Game

A fun, interactive number guessing game built using Python. The computer randomly selects a number between 1 and 100, and the player tries to guess it with the help of higher or lower hints.

This project includes both a command-line version and a Streamlit web application.

## ✨ Features

- Random number generation
- Interactive number guessing
- Higher and lower hints
- Tracks the number of attempts
- Simple and beginner-friendly gameplay
- Streamlit web interface
- Restart option in the web version

## 🛠️ Built With

- Python
- Random module
- Streamlit

## 🎮 How to Play

1. The computer randomly chooses a number between 1 and 100.
2. Enter your guess.
3. The game tells you whether your guess is too high or too low.
4. Keep guessing until you find the correct number.
5. Try to guess the number in as few attempts as possible!

## ▶️ Run the Python Version

Make sure Python is installed on your computer.

Run the following command in your terminal:

```bash
python guess_game.py
```

## 🌐 Run the Streamlit Version

First, install Streamlit:

```bash
pip install streamlit
```

Then run the application:

```bash
streamlit run app.py
```

The application will open in your browser.
